# 表间部署与维护

- 品牌：表间 TableNest；正式域名 `tablenest.137101.xyz`。
- 仓库：`CloudflareFree/tablenest`；Pages Git 生产分支 main。
- 构建：Node 24，`npm run build`，输出 `dist`。不需要运行应用后端，不创建 KV、数据库服务或 Worker Functions。
- SQLite 官方 WebAssembly 运行时随仓库提交，构建时无需下载引擎；版本 3.54.1，下载自 sqlite.org 的官方发布包。保留运行时所附许可。
- 发布只复制工作台实际需要的文件，不部署历史页面、开发配置和凭据。SQL、数据库及结果不会写入 URL 或统计事件。
- 构建生成首页、使用指南与隐私页的 sitemap；不把查询标签、结果或 URL 片段作为索引页。未知路径真实返回 404。
- GA4 使用本站单独数据流。Search Console 脚本使用显式环境变量，密钥保存在仓库外；提交接受与抓取、收录分别记录。

## 验证

```bash
npm test
npm run build
# 使用支持 Pages 路由及 _headers 的本地预览验证 CSP 与 WASM
wrangler pages dev dist --port 8896
npm run verify:browser -- http://127.0.0.1:8896
```

浏览器脚本使用 CHROME_BIN 或本机 Chromium 路径，不额外下载浏览器。真实执行 SQLite，覆盖查询、写入、结构、导入导出、本地持久化、取消、键盘与响应式布局。数据转换测试覆盖带换行/引号的 CSV、重复表头、SQL/HTML 特殊字符、BLOB、重复字段名与大整数。

## 功能边界

数据库文件最大 50 MB；CSV 最大 10 MB、100,000 行，所有字段按 TEXT 导入。查询约 10 秒后被中断，界面预览最多 5,000 行；导出结果使用当前筛选后的预览，完整数据请导出数据库。柱状图最多 50 行，以第一个数字列作数值。

数据库自动保存在 IndexedDB，SQL 标签、历史及收藏使用 localStorage；无痕退出、用户清除存储或浏览器回收空间可能丢失本机数据，请定期导出。取消长查询会重建 Worker 并恢复上次成功操作的数据库快照。包含虚拟表时使用 .db 导出；常规 SQL 导出保留表、数据、索引、视图、触发器和自增序列。

## 回退与更新

更新引擎时使用官方发布包并验证二进制导入导出、64 位整数、长查询中断及本机保存。界面或核心模块更新后递增 sw.js 缓存名，修改固定资源路径的版本号；验收后提交 main。若回归，在 Pages 回退此前成功部署并撤销有问题的 Git 提交。

GA4 的页面访问可向 Google 发送基本浏览元数据，但不发送数据库、文件名、SQL 或结果。统计服务不可达不会阻止 SQL 运算。
